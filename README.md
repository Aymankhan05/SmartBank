# 🏦 SmartBank v2
## 📌 Project Description
SmartBank v2 is a Python console-based banking system developed using Object-Oriented Programming (OOP). It allows users to create bank accounts, log in securely using a PIN, deposit and withdraw money, transfer funds, and view transaction history.

## ✨ Features
- Create Account
- Secure Login with PIN
- Deposit Money
- Withdraw Money
- Check Balance
- Transfer Funds
- Transaction History
- Input Validation
- Exit System

## 🛠️ Technologies Used
- Python 3
- Object-Oriented Programming (OOP)
- VS Code
- Git
- GitHub

## 🚀 How to Run
1. Clone this repository.
2. Open the project in VS Code.
3. Run:
   
   python SmartBank_v2.py
